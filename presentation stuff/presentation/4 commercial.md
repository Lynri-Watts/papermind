| --------- | ------------------------------------------------------------------------- |

3. 完整定价策略底层逻辑  

| 逻辑 | 解释 |
| ---- | -------------------------------------------------------------------------------- |
| 流量 | Freemium免费层降低获客门槛，依托免费高频体验建立产品认知，解决学术用户“不敢付费、担心踩坑”的顾虑 |
| 现金流 | 分级订阅提供稳定持续性收入（Recurring Revenue），算力成本可提前规划，规避Token计费带来的收入剧烈波动； |
| 用户留存 | 年付优惠引导长期付费，降低月度流失率；对比竞品混合计费、点数充值模式，全包订阅消除用户成本焦虑，提升长期留存 |
| 长期增长 | 基础订阅为核心收入，未来仅新增私有文献存储空间、顶级科研模型包等轻量化增值插件提升ARPU，不改动C端全包订阅底层框架，维持简单透明的消费体系 |
| 转化提升 | 结合ROI实证案例（AI节省70%文献阅读、综述撰写时间），搭配无隐形扣费的定价卖点，解决学术人群付费意愿薄弱问题，提升免费转付费转化率（SSRN,2026）。 |
